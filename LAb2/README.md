# Personal Portfolio Website

A responsive personal portfolio website built using React.
It showcases my profile, education, achievements, projects, and contact information.

## Features

- Home page with a short introduction
- About page with education and achievements
- Projects page showcasing personal projects
- Contact page with form validation
- Responsive dark-themed design
- Theme persistence using localStorage
- Initial loading state
- Reusable React components
